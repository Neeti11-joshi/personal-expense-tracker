# Personal Expense Tracker

## About the Project
Personal Expense Tracker is a beginner-friendly Python application that helps users record and manage their daily expenses. It uses CSV file storage to save expense records.

## Features
- Add a new expense with title, amount, category, and date
- View all recorded expenses
- Search expenses by category
- Calculate total expenses
- View monthly expense summaries
- Delete an expense
- Store expense records in a CSV file
- Validate user input and handle basic errors

## Technologies Used
- Python
- CSV File Handling
- Exception Handling

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

```bash
python main.py
```

## Storage
Expense records are stored in `expenses.csv`. The application creates this file automatically if it does not exist.
